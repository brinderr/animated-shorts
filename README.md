# Animated Shorts for Claude

Make viral animated story shorts (2D cartoon characters in a colourful 3D world) with Claude.
No AI video generator, no credits. Claude builds every frame with code and renders it on your own computer.

## Install (2 minutes, no coding)
1. Open the **Claude desktop app** and click the **Code** tab.
2. Paste this and press Enter:

   > Install this skill: https://github.com/brinderr/animated-shorts

3. Then type:

   > Use the animated shorts skill.

Claude installs the free tools it needs (it asks before each one, just click Allow), asks you two questions, and starts working.

## What you need
- Any paid Claude plan with Claude Code.
- A Mac or Windows computer. Everything else is free and Claude installs it for you.

## Two ways to start
- **Copy a style:** paste a link to a short you love. Claude studies it frame by frame and matches the look.
- **Just an idea:** type a topic or "surprise me". Claude uses the built-in style.
